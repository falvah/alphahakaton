# Проверка безопасности — 26 октября 2026

Проверены вход, роли и доступ к чужим объектам, обработка PDF, импорт скорингового JSON, автоматическое решение, ручное одобрение, принятие предложения и настройки развёртывания. Это проверка исходников и локальных сценариев, а не независимый pentest развёрнутой системы.

## Исправления

- Импорт экспертной оценки теперь проверяет свежесть даты, сумму, срок, ИНН и ОГРН. Название, правовая форма, подписант, адрес и цель берутся из сохранённого снимка заявки: JSON не может незаметно изменить их для расчёта.
- Одобрение и принятие предложения запрещены без скоринговой карты, при другой версии карты, устаревших или будущих датах проверок. Демонстрационное решение нельзя принять вне песочницы. При блокировке старого предложения требуется новая заявка с актуальными данными; историю не переписываем.
- Противоречивые поля числа связанных сторон на разных уровнях JSON отклоняются, вместо выбора одного из них.
- Вход больше не обрезает логин и пароль до допустимого префикса. Слишком длинные значения отклоняются. Счётчики попыток читаются с блокировкой внутри транзакции.
- Запуск с `DEBUG=true` вне песочницы запрещён конфигурацией.
- PDF и отправка заявки используют одну multipart-форму. Загруженный документ сохраняется при последующих ошибках валидации; повторная отправка не создаёт дубликат.

## Результаты

- `sh scripts/check.sh`: 143 теста Django и 5 тестов JavaScript; проверки конфигурации, зависимостей и миграций прошли.
- `tests.live_http`: 105 проверок настоящего Gunicorn с отдельной временной базой. При повторной проверке submission-v1 HTTP-прогон выполнен внутри Docker командой `sh scripts/check.sh`; временные отчёты не входят в поставку.
- `manage.py check --deploy` с production-настройками и временным секретом: замечаний нет.
- `pip-audit -r requirements.lock --no-deps --disable-pip`: известных уязвимостей в зафиксированных зависимостях не найдено на дату проверки. Используется Django 5.2.18, содержащий [исправления безопасности от 6 октября](https://www.djangoproject.com/weblog/2026/oct/06/security-releases/).
- Bandit: два замечания низкого уровня B101 на `assert` в исходном ML-движке. Они проверяют внутренние инварианты расчёта, не заменяют авторизацию или валидацию входа. Исходный движок оставлен неизменным для независимой сверки.
- Дополнительно проверены 364 варианта повреждённых скалярных полей скоринга: неожиданных исключений не получено.

Браузерная проверка интерфейса не выполнена: встроенный браузер недоступен. HTTP-тесты проверяют серверный сценарий, но не заменяют взаимодействие в браузере. Ограничения обработки PDF, внешних источников и инфраструктуры описаны в [security.md](security.md). Отсутствие найденных проблем не гарантирует отсутствие всех уязвимостей.
