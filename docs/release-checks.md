Повторный полный прогон: `sh scripts/check.sh`. Сервер и HTTP проверяются в Docker, JavaScript — установленным Node.js. Рабочие данные не используются. Дополнительные инструменты аудита установлены во временное окружение вне рабочего образа и не включены в зависимости приложения.

Проверка исходной модели сохраняет побайтовое соответствие предоставленному пакету. Это подтверждает интеграцию, но не калибровку PD и не качество риск-прогноза на реальных клиентах.

Браузерный визуальный прогон, нагрузочное тестирование, аудит WCAG и независимый pentest не выполнены. Границы прототипа и оставшиеся недостатки описаны в [criteria-review.md](criteria-review.md) и [security.md](security.md).
